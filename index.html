About this page

This site is deployed with GitHub Pages. The page is intentionally static: one HTML file, one stylesheet and one small script. That keeps the attack surface small and makes the network behaviour easy to observe in developer tools.

DNS first

Before any bytes of this page arrive, the resolver turns the name into an IPv4 address. GitHub Pages publishes several A records so the client can reach different edge locations.

Then TCP and TLS

The browser opens a TCP connection to port 443, performs the TLS handshake and only then sends an HTTP request. A packet capture shows this as DNS, then SYN / SYN-ACK / ACK, then the handshake.

Why HTTPS matters

Plain HTTP would expose the request and response on the wire. TLS gives confidentiality and integrity, and the HSTS header tells the browser to keep using HTTPS on later visits.
